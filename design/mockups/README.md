# Rolodexian Retrofuturist UI Concepts

These mockups explore a unified command-center visual system across the four core
Rolodexian surfaces:

1. `01-personnel-index.png` — contact search, filtering, overview, and strength
   scanning.
2. `02-contact-dossier.png` — single-contact profile, interaction history,
   accounts, images, and relationship context.
3. `03-relationship-network.png` — topology view with selected-record context,
   link-strength encoding, filters, and camera diagnostics.
4. `04-record-input-console.png` — dense record editing with validation,
   completion state, and a live preview.

## Visual system

- Near-black plum/black backgrounds keep the interface cinematic without
  sacrificing contrast.
- Hazard orange defines structure, navigation, active controls, and panel edges.
- Phosphor green means verified, connected, live, or strong.
- Signal red is reserved for weak/stale relationships, alerts, and destructive
  actions.
- Amber represents moderate strength, warnings, and unsaved state.
- Acid violet is a sparse focus/accent color, never a dominant surface color.
- Major headings use a condensed industrial face; records and telemetry use a
  technical monospace.
- Panels use thin double-line frames, clipped corners, registration ticks, and
  restrained CRT bloom/scanlines.

## Generation prompt set

All four images were generated as high-fidelity, shippable desktop web UI
mockups. The supplied asteroid-tracker screenshots were used only as references
for mood and interface language. Each prompt explicitly required an original
design with no anime characters, franchise names, logos, insignia, or copied
screen layouts.

The shared prompt requested:

> A late-1990s Japanese mecha command-center interface for ROLODEXIAN using
> near-black surfaces, hazard-orange frames, phosphor-green live data,
> signal-red alerts, amber warnings, a restrained violet focus accent,
> condensed white headings, monospaced telemetry, sharp chamfered panels,
> registration marks, segmented meters, subtle scanlines, disciplined glow,
> and practical desktop-product usability.

Screen-specific prompts then preserved the real application's information
architecture:

- Personnel Index: top product status, search/filter rail, six dossier cards,
  relationship-strength meters, and mission status.
- Contact Dossier: identification scan, summary, interactions, social accounts,
  traits, relationship mini-map, images, and custom fields.
- Relationship Network: readable reticle nodes, strength-coded links, selected
  record, filters, legend, camera state, and graph metrics.
- Record Input Console: section navigator, core profile form, segmented strength
  control, validation, completion, live preview, and sticky commit actions.
